# Code of Conduct

## The Short Version

Be respectful. Be constructive. Don't be a jerk.

## The Longer Version

This project is maintained by a small team. We want contributions from anyone who's interested, regardless of experience level, background, or identity.

**Expected behavior:**

- Be patient with newcomers
- Give constructive feedback on PRs
- Focus on the code, not the person
- Respect differing viewpoints and technical preferences

**Unacceptable behavior:**

- Harassment, insults, or personal attacks
- Trolling or deliberately derailing discussions
- Publishing others' private information
- Any conduct that would be inappropriate in a professional setting

## Enforcement

If someone is violating this code of conduct, report it by opening an issue or contacting the maintainer directly. Reports will be reviewed and handled appropriately.

## Scope

This applies to all project spaces: issues, pull requests, discussions, and any public channel where you're representing this project.
